# 观点拆解方法

## 1. 五层观点树

从上到下重建作者的表达：

1. **议题**：视频在讨论什么问题。
2. **中心论点**：作者希望观众最终相信什么。
3. **子观点**：中心论点成立所依赖的理由或步骤。
4. **证据**：数据、案例、引用、演示、个人经验或类比。
5. **结论动作**：作者希望观众如何理解、选择或行动。

中心论点尽量写成可被反驳的完整句子，不要只写主题词。

## 2. 主张类型

为每个观点标记一种主要类型：

| 类型 | 识别问题 | 常见核验方式 |
|---|---|---|
| 事实陈述 | 事情是否真实发生或数据是否准确？ | 原始数据、正式文件、直接记录 |
| 因果判断 | A 是否真的导致 B？ | 机制、对照、排除替代解释 |
| 价值判断 | 依据什么价值标准说好或坏？ | 标准是否明确、是否一致 |
| 预测 | 对未来的判断基于什么变量？ | 假设、基准率、情景范围 |
| 行动建议 | 对谁、在什么条件下有效？ | 适用边界、成本、风险、可逆性 |

## 3. 论证链

用以下结构压缩论证：

> 因为【证据/前提】，通过【推理机制】，所以【子观点】，最终支持【中心论点】。

检查四类缺口：

- **证据缺口**：只有结论，没有数据或案例。
- **代表性缺口**：用个案代表普遍规律。
- **因果缺口**：把相关性、先后顺序或个人体验当成因果。
- **边界缺口**：没有说明对象、时间、场景或失败条件。

## 4. 证据等级

按来源质量与贴合度给出定性等级：

- **强**：可核查的一手资料、原始数据、完整演示，且直接支持主张。
- **中**：可追溯的二手资料、多个一致案例或较完整个人实践，但仍有外推限制。
- **弱**：单一个案、未给来源的数据、权威背书、类比、情绪或大量点赞。
- **无**：视频只提出判断，没有提供可识别证据。

证据等级评价“视频提供了什么”，不是对世界真相的最终判定。

## 5. 双置信度

分别输出：

- **内容还原置信度**：对“作者到底说了什么”的把握。
  - 高：完整视频/完整字幕，并可定位关键片段。
  - 中：完整字幕或视频可访问，但画面/评论/时间戳不完整。
  - 低：只有页面文字、零散画面或部分转写。
- **观点可信度**：对“主张是否得到充分支持”的判断。
  - 高：关键主张有强证据，推理完整，适用边界清楚。
  - 中：方向有支持，但存在样本、因果或边界问题。
  - 低：证据弱、逻辑跳跃明显或关键事实无法核验。

## 6. 反方测试

对重要观点至少问一次：

- 哪个事实若为假，会直接推翻它？
- 最强反例是什么？
- 是否存在更简单的替代解释？
- 对哪些人或场景不适用？
- 作者是否把“我有效”扩大成“人人有效”？

反方测试用于限定结论，不是为了机械唱反调。

## 7. 行动转译

将视频转化为用户可用的三层结果：

1. **可直接采用**：低风险、证据充分、条件匹配。
2. **值得小试**：方向合理但证据有限，设计低成本可逆实验。
3. **暂不采用**：风险高、证据不足或与用户条件不匹配。

每条行动建议写清：对象、动作、前提、成本、验证指标和停止条件。
