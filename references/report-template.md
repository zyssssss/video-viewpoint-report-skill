# 飞书观点报告模板

按以下顺序输出。证据不足时保留关键字段并写“未获取”。

## 1. 标题与来源

- 标题：`视频观点拆解｜{视频标题}｜{日期}`
- 原视频链接、平台、作者、发布时间、时长
- 分析所依据的材料：完整视频 / 完整字幕 / 部分字幕 / 页面信息 / 抽样评论

## 2. 一句话结论

用 callout：

> 这条视频主张【中心论点】；最有价值的是【可复用认知】，最大缺口是【证据或逻辑问题】，建议【采用 / 小试 / 暂不采用】。

同时展示：内容还原置信度、观点可信度。

## 3. 视频内容速览

| 阶段/时间 | 讲了什么 | 在论证中的作用 | 证据来源 |
|---|---|---|---|
| 开头 |  | 提出问题/承诺 | 字幕/画面 |
| 中段 |  | 解释/举证 | 字幕/案例 |
| 结尾 |  | 总结/行动建议 | 字幕/CTA |

## 4. 观点树

- 议题
  - 中心论点
    - 子观点 A
      - 证据
    - 子观点 B
      - 证据
  - 作者建议的行动

## 5. 观点审计

| 观点 | 类型 | 作者依据 | 推理链 | 隐含假设 | 证据等级 | 判断 |
|---|---|---|---|---|---|---|
|  | 事实/因果/价值/预测/建议 |  |  |  | 强/中/弱/无 | 成立/部分成立/待核验/不成立 |

“不成立”只在反证充分时使用；无法核验时写“待核验”。

## 6. 最强观点与最大漏洞

用两个并列 callout 或小节：

- **最强观点**：内容、为何有价值、关键证据、适用边界。
- **最大漏洞**：缺口、可能造成的误判、需要补充的证据。

## 7. 反方与适用边界

- 最强反例或替代解释
- 哪些人/场景适用
- 哪些人/场景不适用
- 尚未回答的问题

## 8. 评论区信号

仅分析实际可见评论，按支持、质疑、追问、行动/购买意图分组；注明可访问评论数量与抽样局限。

## 9. 给用户的行动建议

| 优先级 | 动作 | 前提 | 成本/风险 | 验证指标 | 停止条件 |
|---|---|---|---|---|---|
| 采用/小试/暂缓 |  |  |  |  |  |

## 10. 证据与缺失项

- 关键时间戳与短摘录
- 页面指标与采集时间
- 未获取的字幕、画面、评论或数据
- 这些缺失项如何影响结论

## 11. 最终摘要

```text
中心论点：
关键子观点：
最强证据：
最大漏洞：
适用边界：
行动建议：
内容还原置信度：
观点可信度：
```
